# web_version

Recognition-only demo, deployed to GitHub Pages as-is.

## Rules

- No external libraries, no build step.
- Must work when opened via `file://` (double-click): no `fetch`, no ES modules. Data is loaded as classic scripts that set globals — `model.js` (`window.MNIST_MODEL`), `golden.js` (`window.MNIST_GOLDEN`).
- `model.js` and `golden.js` are generated by `../desktop_version/train.py` and `make_golden.py`. Never edit them by hand.
- `preprocess.js` must stay identical in behavior to `../desktop_version/preprocess.py` (see root CLAUDE.md).

## Files

- `index.html` — UI: 280×280 black canvas, 지우기/인식하기 buttons, big predicted digit, 확신도, top-3 candidate bars. Recognizes on pointer release; Esc clears, Ctrl+Z undoes; ignores a second pointer while drawing; stacks vertically on narrow screens. Shows an error and disables buttons if the model is missing or malformed.
- `preprocess.js` — `window.MnistPre` (`toMnist`, `areaDownscale`, `roundHalfUp`, `upscale10`, `grayFromImageData`), DOM-free.
- `mlp.js` — `window.Mlp` (`decodeBase64`, `loadModel` which throws on bad shapes, `predict`).
- `tests.html` — open in a browser; the summary at the top must read all passed (preprocessing ≥ 198/200 exact, full pipeline ≥ 199/200 agreement with Python, forward error < 1e-4).

For local preview in Claude Code, `.claude/launch.json` has a `web_version` server (`python -m http.server 8123`); the Browser pane renders `file://` pages without their sibling scripts.
